# Drop anywhere

Drag files from Finder onto any part of VoxStudio. A dashed outline shows that you can drop. When you let go, VoxStudio asks what to do:

| You drop | Choices |
|---|---|
| **Audio** (WAV, MP3, M4A, FLAC, OGG…) | **Clone this voice**, **Transcribe**, **Clean it up**, **Change the voice** |
| **Video** (MP4, MOV, MKV, WebM…) | **Dub this video** (pick the language right on the card), **Transcribe**, **Clean up its audio** |
| **A book** (EPUB, DOCX) | **Make an audiobook**, **Make a story** |
| **Text** (TXT, Markdown) | **Open in Studio**, **Make an audiobook**, **Make a story** |
| **Several audio or video files** | **Transcribe all** |

Each choice takes you straight to the right place with the file already loaded:
- A voice to clone opens in **Clone** with its name filled in.
- A book opens ready to cast.
- A dub starts preparing immediately.

Transcriptions run in the background, and a notification with **Open** appears when each one is ready.

Pages that have their own drop area, such as Clone's upload box or Dub's video box, still handle files dropped right on them. Press **Esc** or click outside the sheet to cancel.
