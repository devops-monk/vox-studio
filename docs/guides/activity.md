# Background work & Activity

Some work takes more than a moment: long passages today, and dubbing, audiobooks and model downloads soon. VoxStudio runs that work in the background so you can keep going.

## 1. Start something long
In **Try a voice** on Home, paste more than a few paragraphs. The hint under the text box changes to **Long text · renders in the background**. Click **Speak**.

- The orb sweeps and counts up: **Rendering 33%**, **67%**…
- **Speak** becomes **Cancel** until the render finishes.
- When it's done, playback starts automatically.

## 2. Watch it in Activity
The **Activity** button (checklist icon) in the toolbar shows everything running:

- While work is running, a **progress ring** fills around the icon, so you can see progress from any page.
- A number badge appears when more than one job is waiting.
- Click it to open the Activity list: live progress bars, what each job is doing right now, and when it finished.

## 3. Cancel, replay, tidy up
- **✕** cancels a queued or running job. Running jobs stop within about a sentence.
- **▶** plays the result of a finished render.
- **Clear finished** empties the list. Your takes are kept.

## When it's done
A notification pops up with a **Play** button, even if you've moved to another page. Failures show up the same way, with the reason.

> **Good to know:** jobs run one at a time, in order. If you quit VoxStudio mid-render, that job is marked as interrupted the next time you open the app. Just start it again.
