# Projects

Keep related work together, such as everything for a launch video, a course or a podcast series, and find every file you've exported.

## Create a project
Open **Projects**, type a name in the dashed card, and click **Create**. Each project gets a colour; change it in the project view.

## Add things to a project
Look for the **folder button** wherever you work:
- **Studio**: hover over a take and click the folder icon.
- **Transcribe**: **Project** in the transcript header.
- **Dub**: **Project** next to Render.
- **Stories & audiobooks**: **Project** in the book header.

Tick one or more projects, or type a name under **New project…** to create one and add the item in one step.

## Inside a project
Items are grouped as **Takes**, **Transcripts**, **Dubs** and **Stories & audiobooks**.
- **Play** a take, or **Open** anything else to jump straight to it.
- **✕** removes an item from the project. The item itself isn't deleted.
- If an item was deleted elsewhere, it's shown dimmed.

**Exports** lists every file saved from the project's items. **Show in Finder** takes you straight to it.

## All exports
The Projects page also lists **every** file VoxStudio has saved, newest first, so you never lose track of where something went. Files that have since been moved or deleted are marked.

Deleting a project keeps all of its items.
